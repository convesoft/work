## Scope

Build the pure graph layer over loaded items. Resolve the four relation types, validate their structure, derive reverse navigation and aggregate state, and explain which manual items are executable.

This slice reports graph eligibility, not an ownership reservation. Later coordination adds claim eligibility using the same lifecycle evaluator.

## Acceptance criteria

- Parent and depends_on affect lifecycle; related and discovered_from remain informational.
- Each parent is singular; related navigation is symmetric without duplicate stored assertions.
- Missing targets, duplicate semantic edges, self-relations, hierarchy/dependency cycles, and combined lifecycle deadlocks are diagnosed.
- Manual parents wait for required children and then retain their own explicit final execution.
- Aggregates are never executable, empty aggregates remain open, and reopening or adding unfinished children updates their effective state.
- Ancestor prerequisites gate descendants without propagating a parent's internal child wait back down.
- Readiness and explanations use one evaluator, with priority then canonical-ID ordering.
- An invalid selected graph refuses readiness evaluation; another valid project remains independent.
- The bootstrap graph initially exposes only its first manual child, then its successor as the predecessor is completed in a test fixture.

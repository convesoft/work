## Scope

Define the scope/filter schema and implement one atomic operation that selects and claims a ready item from the selected checkout. Preserve accepted priority and ID ordering; scope this to version items without a new product concept.

## Acceptance criteria

- Scoped list and claim-next use the same selected-view graph and explicit filters.
- Claim-next selects by priority 0–4 then canonical ID and reserves exactly one eligible item atomically.
- Concurrent callers cannot receive the same coordination identity; no eligible work returns a structured empty result.
- CLI and MCP expose matching filters, errors, and readiness explanations with race and worktree-view tests.

## Scope

Define named session hints and persistent workspace associations in operational state. Keep execution and physical worktree creation external; one-time workers need no named registration.

## Acceptance criteria

- A claim can reference an optional run-scoped session and reusable workspace record.
- Session removal or claim release does not delete the worktree or erase useful workspace context.
- Selected-worktree identity and a surviving checkout are represented without treating a shared index as durable truth.
- CLI/MCP operations and tests cover reuse, multiple users, restart, and cleanup eligibility.

## Mara contracts

`DES-CLAIM-CONTEXT`, `DES-WORKSPACE-ASSOCIATIONS`, `REQ-WORKTREE-VIEWS`, `REQ-EXTERNAL-EXECUTION`. Resolve any unsettled operation or storage details in [open questions](../../docs/open-questions.mara.md) and update canonical Mara knowledge before implementation.

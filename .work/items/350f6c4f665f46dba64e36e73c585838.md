## Scope

Define bounded squash/finalization that retains a digest extension on the existing root in a surviving checkout before wisp cleanup. Add explicit discard of selected run-owned wisps or full ephemeral run context without a digest, including abandoned unfinished work. Settle operation schemas, extension serialization and repeat-call behavior in Mara. Do not create a separate digest item or close the root. Keep narrative digest caller-authored and refuse unsafe cleanup while outside references remain. Preserve feature-level history without committing every operational transition; a branch merge alone does not archive shared files.

## Acceptance criteria

- A finished run with no active claims can retain a caller-authored digest on its root, preserving the supplied text and existing root content. The manual root may remain open; no child digest item or implicit completion is created.
- Interrupted squash preserves evidence for inspection/continuation and never removes wisps before digest retention. Verify bounded repeat-call behavior and do not assume cross-filesystem rename atomicity.
- Finishing alone retains wisps. Explicit discard needs no digest, does not close the root or material items, and preserves their files and existing digests. Selected discard leaves other wisps and the run intact.
- Discard rejects active target claims and references from surviving items or needed handoffs, reporting blockers; references wholly within the deletion set do not block it. Partial deletion is reported for caller inspection/continuation.
- Wisps and named-session bindings remain until retention obligations pass or explicit discard is eligible. Shared workspace files and cross-run handoffs follow independent lifecycles. No template application records are introduced.
- CLI/MCP and crash/restart tests verify root extension, unchanged root completion, squash cleanup and digest-free discard across linked worktrees.

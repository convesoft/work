## Scope

Deliver the first usable slice of Work against these existing version-1 item files. A caller can create and inspect items, connect dependencies, inspect readiness, close a prerequisite, and observe the dependent become ready through both CLI and MCP.

This is an aggregate delivery item. Its children are the required implementation work; it has no separate execution or stored state.

## Acceptance criteria

- The existing bootstrap backlog loads directly, with stable identities and unchanged Markdown bodies.
- The shared operation layer serves equivalent behavior through CLI and MCP.
- Ordinary dependencies, required children, aggregate completion, cancellation-as-closure, and reopening follow the accepted contracts.
- Invalid selected graphs stop scheduling while inspection and repair remain possible.
- The complete loop is demonstrated on an isolated copy of this backlog, without modifying the real issues to simulate test completion.
- No implementation issue is completed solely because its specification or test definition exists.

## Boundaries

This delivery covers durable item files and the graph loop. Claims, shared SQLite coordination, template/run publication, named sessions, handoffs, workspace cleanup, and squash remain later slices of the initial release; they are not silently represented as implemented here.

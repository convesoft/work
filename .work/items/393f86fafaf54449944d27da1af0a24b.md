## Scope

Add the command-line adapter for the shared durable-item and graph operations. Record the selected command names, structured result/error shapes, and exit behavior in Mara; avoid placing scheduling or persistence rules in the presentation layer.

## Acceptance criteria

- A user can create, inspect/list, update metadata, add/remove relations, explain readiness, close, and reopen items.
- Human output shows readable IDs; structured JSON retains canonical identities and machine-distinguishable errors.
- Explicit worktree selection reads and writes the chosen durable view without switching the caller's branch.
- Empty readiness, malformed source, missing IDs, ambiguous prefixes, invalid graphs, and conflicting writes have distinguishable outcomes.
- The create → depend → ready → close → ready loop works in a disposable fixture.
- Tests invoke the executable and parse JSON rather than matching human prose.
- No deferred operation is advertised as implemented.

## Mara contracts

`REQ-CLI-JSON`, `REQ-CLI-MCP-PARITY`, `DES-INTERFACE-ADAPTERS`, `REQ-WORKTREE-VIEWS`, and `VER-CLI-CONTRACT`.

## Scope

Prepare and verify the provisional `0.1.0-beta.1` release after the beta implementation aggregate completes. Select the actual version in this item; re-evaluate it if alpha publication changes the sequence. Use the repository release process, a separate release PR, and protected publication.

This item records release evidence; it is not authorization to merge, tag, or publish. Follow [delivery conventions](../../docs/delivery.mara.md).

## Acceptance criteria

- All beta implementation children are merged, accepted, and the aggregate is complete.
- The candidate uses one selected main revision with aligned version, changelog, artifacts, packaged CLI/MCP smoke, and documented feature limits.
- Required GitHub protection and registry trust are checked as actual external settings.
- Authorized publication produces an immutable annotated tag and matching packages; public install/smoke and publication evidence are recorded.
- A failed or partial publication leaves this item open with retry context; merge alone does not complete it.

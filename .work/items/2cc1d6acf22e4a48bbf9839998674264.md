## Scope

Implement addressed opaque messages stored in the sending run, incoming context on reads/acquisition and filtered inbox/list for item/session/run recipients. Support parent and qualified cross-run destinations without a global message registry or receiver-retention policy.

## Acceptance criteria

- Parent and sibling-run reports remain physically in sender files with exact bodies.
- Resolved item inspect/acquire and inbox/list expose the intended incoming context and unavailable-source diagnostics.
- Messages add no dependencies or delivery proof; no notification/watch/receipt/acknowledgement service is advertised.
- Unread or unfinished receivers cannot block sender disposal; no automatic forwarding, upward copy or receiver-state pruning survives.
- Real CLI/MCP and publication-order tests cover multiple destinations, restart, retirement context and partial close outcomes.

## Mara contracts

`REQ-SENDER-HANDOFFS`, `DES-SENDER-HANDOFFS`, `VER-SENDER-HANDOFFS`. Read the accepted beta.2 contracts and freeze any still-draft wire details before behavior changes.

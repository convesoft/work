## Scope

Exercise the delivered slice using isolated copies of the real authored backlog. Confirm that Work can replace manual file handling without reimport, identity replacement, or body rewriting.

This is the final acceptance activity for this slice, not a reason to defer tests in earlier implementation items.

## Acceptance criteria

- CLI and MCP both load the copied backlog and agree on identities, parent/child structure, and initial readiness.
- Closing each prerequisite in the fixture exposes the next task; the aggregate becomes done only after all its children resolve.
- Reopening a prerequisite recomputes aggregate state without automatically reopening completed manual descendants/dependents.
- A create/relate/close/reopen round trip preserves existing body bytes and reloads correctly after process restart.
- Linked-worktree fixtures demonstrate selected-view isolation.
- Invalid headers, ambiguous IDs, and invalid graph fixtures fail with the specified diagnostics through both interfaces.
- User documentation explains the supported commands/tools, manual-to-tool transition, and currently unimplemented later slices.
- Actual test results and limitations are reported; Mara verification definitions alone are not treated as passing evidence.
- The real backlog is updated only for work actually completed, never by the acceptance simulation.

## Mara contracts

`VER-BOOTSTRAP-COMPATIBILITY`, `VER-DURABLE-ROUNDTRIP`, `VER-SURFACE-PARITY`, `VER-WORKTREE-ISOLATION`, and `VER-SIMPLE-LIFECYCLE`.

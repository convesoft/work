## Scope

 Define cleanup-target and retry protocol. Represent removal as an ordinary explicit Work item; external tooling performs physical Git worktree deletion and reports the result.



 ## Acceptance criteria

 - Cleanup checks active executions, shared workspace users, unfinished work, and retained commits/results/handoffs before allowing removal.
- Marking a workspace as closing rejects new assignments; failure retains inspectable context and supports retry.
- Successful external removal clears operational workspace records without implicitly deleting work from claim release, session removal, or run finalization.
- CLI/MCP and recovery tests cover interruption before and after physical deletion.

 ## Mara contracts

 `REQ-WORKSPACE-CLEANUP`, `DES-WORKSPACE-ASSOCIATIONS`, `REQ-HANDOFF-CONTEXT`. Resolve any unsettled operation or storage details in [open questions](../../docs/open-questions.mara.md) and update canonical Mara knowledge before implementation.

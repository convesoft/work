## Scope

 Define the versioned YAML template contract and CLI/MCP discovery, validation, and preview. Templates express ordinary item graphs and parameter substitutions; optional model/thinking defaults remain hints to external executors.



 ## Acceptance criteria

 - Valid templates are found under `.work/templates/` and invalid schemas, references, or parameters fail clearly.
- Preview returns the exact prospective item graph and substitutions without publishing a run or modifying durable items.
- Template application can distinguish explicit item hints from template defaults and preserves opaque rendered bodies.
- CLI/MCP parity and fixtures cover repeatable review/fix/consolidation graphs.

 ## Mara contracts

 `REQ-GRAPH-TEMPLATES`, `REQ-EXECUTOR-HINTS`, `DES-TEMPLATE-RUNS`, `REQ-OPAQUE-BODIES`. Resolve any unsettled operation or storage details in [open questions](../../docs/open-questions.mara.md) and update canonical Mara knowledge before implementation.
